# 自律 2.0

根据最新需求重构的 Android Compose 工程。页面固定为：**每日任务、长期计划、日历、每日小记、设置**。专注模式不再占用导航页，只会在点击每日任务的“开始”后自动进入。

## 已实现

- 首屏展示新版图标、`自律，做强大的自己` 及英文；保留微信、QQ 登录入口和离线模式。
- 每日任务只有红色未完成和绿色已完成两种状态，不能手动改状态。设置分钟后点击开始，前台服务继续倒计时；完成后自动变绿并播放系统传统提示音。
- 倒计时会以持续通知显示在通知栏；离开 App 后仍继续运行。任务提醒使用时/分轮盘，通知文案为“您的「任务名」还没有做”。
- 每个任务显示连续完成天数；今日完成度只计算当天每日任务。
- 长期计划只有截止日期（年/月/日轮盘）和子目标。默认一个子目标；可添加、逐项切换状态，并以红黄绿显示进度。
- 日历只展示每日任务：任务全部完成的日期为绿色，否则红色；创建任务之前的日期保持白色。点击日期显示当天待办。
- 每日小记支持按日期轮盘读取和保存。
- 设置仅包含深色模式、主题色、字体滑块，以及将已安装 APK 一键分享给微信/QQ 等应用的系统分享入口。

## 必须补充的第三方登录配置

微信和 QQ 的真实 OAuth 登录不能使用占位账号或伪造授权。需要分别提供：

- 微信开放平台 App ID、Universal Link、Android 包名与签名；
- QQ 互联 App ID、Android 包名与签名；
- 两个平台审核通过后的回调配置。

工程当前提供清晰的登录入口和本地模式，不会冒充“已登录”。取得上述凭据后即可接入官方 SDK 和回调处理。

## 构建

使用 Android Studio 打开 `zilu-upgrade`，等待 Gradle Sync 后选择 **Build > Build APK(s)**。首次启动请选择是否授予通知权限；拒绝后，提醒和前台倒计时通知将受系统限制。

原文件只提供了已编译 APK，没有原始签名密钥。若新 APK 的签名与旧版不同，Android 要求先卸载旧版才能安装。
