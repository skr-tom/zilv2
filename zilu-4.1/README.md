# 自律 4.0

Android + Jetpack Compose。页面固定五个：**每日任务、长期计划、日历、每日小记、设置**。
专注模式不占导航页，点任务的「开始」后自动进入全屏专注。

### 关于「到点不震动」的根因

Android 8+ 之后通知的声音/振动由**通知渠道**决定，而不少国产 ROM 会直接忽略渠道里的 `vibrationPattern`；
另外旧代码里「提醒时振动」这个开关虽然存在，却完全没有接到通知链路上，关掉响铃时走的还是一条 `enableVibration(false)` 的渠道。

这轮做了四层修复：

1. 渠道拆成三条：`响铃 + 振动` / `仅振动` / `静音`，按「提醒时响铃」「提醒时振动」组合自动选。
2. 通知 builder 上再显式写一次 `setVibrate`（兼容旧版本与部分 ROM）。
3. **主动调用系统 `Vibrator`** 振一次（截止提醒、专注完成、测试通知各一次），绕开 ROM 对渠道振动的拦截 —— 这是最关键的一层。
4. 用户自选铃声写入「任务截止提醒」「专注完成」两个渠道；换铃声时删掉旧渠道重建（渠道创建后系统不允许改声音）。自定义 URI 读不到时自动回退系统默认音，不会变成哑巴。

设置页「铃声与振动」里四项开关：**提醒时响铃 / 提醒时振动 / 完成任务时响铃 / 完成任务时振动**，加上「提醒铃声 → 选择」入口。

## 首轮升级做了什么

### 1. 通知（重点修复）

之前的推送不生效，主要原因有四个，已逐项处理：

| 问题 | 现象 | 现在的做法 |
| --- | --- | --- |
| 通知小图标用的是系统资源 `android.R.drawable.*` | 在 Android 8+ / 国产 ROM 上被渲染成白块或直接不显示 | 自绘白色沙漏矢量图 `ic_stat_zilu.xml`，并把沙漏 Logo 作为大图标显示在通知右侧 |
| 提醒渠道重要性是 `LOW` | 通知被折叠到通知栏底部，不弹横幅、锁屏看不到 | 「任务截止提醒」「专注完成」都改为 `IMPORTANCE_HIGH` |
| 沿用了旧渠道 ID | 用户曾经关掉过渠道，重建同名渠道不会恢复 | 渠道 ID 全部换成 `_v4`，并自动清理旧的 `_v2` 渠道 |
| 只用 `SCHEDULE_EXACT_ALARM` | 用户没去设置里手动授权时，退化成不精确闹钟，Doze 下可能延迟十几分钟 | 增加 `USE_EXACT_ALARM`（Android 13+ 系统直接授予） |

另外：

- 提醒通知的 ID 按任务固定，不会每天堆一条。
- 设置页有**通知自检面板**：通知权限、两个渠道是否被关、精确闹钟、电池优化，逐项显示状态并提供「去开启」按钮；「发一条测试通知」后询问是否收到，收到即收起该面板。
- 专注时的常驻通知加了 `FOREGROUND_SERVICE_IMMEDIATE`，切后台后立即出现在通知栏，并带一个「退出专注」按钮。

### 2. 专注中途退出按秒扣时

任务按秒存 `durationSeconds`（计划时长）和 `remainingSeconds`（剩余时长）。

- 计划 1 分钟，专注 30 秒后退出 → 任务剩 `0:30`，卡片显示「已做一部分，还剩 0:30」，按钮变成「继续」。
- 下次点「继续」从 30 秒接着计时；正常走完才写入完成记录并把时长复原。

### 3. 提醒时间改为手动输入

「__ 时 : __ 分」两个数字输入框，校验 0~23 / 0~59，填错时保存按钮禁用。

### 4. 长期计划三级

```
文件夹（第一级，每个文件夹一套颜色）
└── 计划（第二级，嵌在文件夹卡片里，可独立勾选完成）
    └── 子计划（第三级，唯一可以设「完成日期-月-日」的一层）
```

- 二级计划直接列在一级文件夹卡片内部，点计划展开第三级子计划。
- 只有子计划有「月 / 日」手动输入框，可以为空；过了日期标红「已逾期」。
- 文件夹有 8 套配色，卡片底色、图标、进度条跟着变。

### 5. 日历

- 月历卡片：月份前后翻页，点日期行跳到任意年月，周一为一周第一天。
- 每个日期格子最多显示 **3 条**当天待办的彩色标签，超过显示 `+N 更多`。
- 下方待办卡片：左侧彩色拖拽把手 + 浅色底 + 右侧方形勾选框。
- **上下拖动**：按住左侧色条拖动调整顺序，松手写入顺序；拖动过程中其它卡片整行让位，不会重叠。
- **完成后自动沉底**：绿色 ✓ 并自动排到最下面，未完成的往上走。
- 长按标题删除该条待办。

### 6. 每日小记

- 顶部日期行可点开**日期选择器**，能补写任意一天；每天内容独立保存。
- 停止输入 0.6 秒自动保存到当前选中日期；下方「往期小记」按日期倒序，点开可继续写。
- 不是今天时显示「回到今天」。

## 构建

用 Android Studio 打开 `zilu-4.0` 根目录（不是 `app`），等待 Gradle Sync 完成后
**Build > Build Bundle(s) / APK(s) > Build APK(s)**。

- 需要 JDK 17（Android Studio 自带）、compileSdk 35。
- 仓库里没有放 `gradle-wrapper.jar`，命令行 `./gradlew` 需要先执行一次 `gradle wrapper`；
  直接用 Android Studio 构建则不受影响。
- 旧版 APK 的签名密钥未知，如果新包签名不同，需要先卸载旧版本再安装。

## 装好之后建议做的三件事（国产 ROM 尤其重要）

1. 首次启动点「允许」通知权限。
2. 设置页 →「铃声与振动」→ 点「提醒铃声」选一个本地铃声；再到「通知与提醒」逐项检查，点「发一条测试通知」，**确认有响铃和振动后点「收到了」**（之后自检面板就不再出现）。
3. 小米 / 华为 / OPPO / vivo 再到系统设置里给「自律」打开**自启动**、**后台弹出界面**，电池策略选**不限制**。

## 数据兼容

存储 key 为 `zilu_v4`，本轮新增的字段都有默认值，旧数据不会丢：

- 旧任务的「分钟」转成秒级时长；
- 旧计划统一放进「我的计划」文件夹，旧子目标转成子计划；
- 旧待办的排序在读取时按日期规整一次（未完成在前、已完成沉底），统一改用 `sortOrder` 表达。

微信 / QQ 真实 OAuth 登录仍需要官方 AppID 与签名配置，当前保留入口与离线模式，不会伪装已登录。
