# 自律 2.0（升级工程）

这是从所提供的已编译 APK 重建的 Android Compose 工程。原压缩包仅有 `app-debug.apk`，没有可修改的源码或签名密钥；因此本工程保留了原包名 `com.zilu.app`，并把版本升为 `2.0.0`。

## 已实现的升级内容

- **每日任务**：红（未完成）/ 黄（进行中，按 50% 计入）/ 绿（已完成）；每天、每周重复；提醒时间；每次状态变化有时间记录。
- **计划表**：大计划、可编辑的完成时间说明、截止日期、子目标、子目标进度和自动红黄绿判断；逾期只提示，不改变状态；可编辑完成心得。
- **软删除**：计划删除后进入“删除记录”，可恢复，历史记录保留。
- **自律日历**：整月颜色点位；点日期可看当天任务与任务/计划状态变更。
- **专注模式**：25/50 分钟和自定义时长、暂停不计时、结束确认、专注记录、完成提醒。
- **设置**：深色模式、三种主题色、三档字体、传统/导入音频提示、完成记录按日期筛选、删除记录、每日总结、JSON 导出与恢复。
- **离线自动保存**：每次新增、状态变更、心得和设置变更立即写入本机；提醒使用 Android 通知。
- **图标**：应用了新的金色沙漏图标 `app/src/main/res/drawable/zilu_icon.png`。

## 构建

1. 使用 Android Studio 打开本目录 `zilu-upgrade`。
2. 等待 Gradle Sync 下载 Android/Compose 依赖。
3. 选择 **Build > Build APK(s)**，生成 debug APK。

本工作区没有 Android SDK、JDK 或 Gradle，因此这里无法进行本机编译验证。首次在手机安装时，请授予通知权限以接收计划提醒。

> 旧 APK 若由不同签名证书生成，Android 不允许直接覆盖安装。先从旧版导出数据（若旧版支持）或保留旧版，再卸载它后安装 2.0；之后使用 2.0 的“导出备份/恢复备份”迁移数据。

## 数据边界

数据默认保存在设备本地 `SharedPreferences`；备份为可读 JSON。导入的提示音会保留对用户选择文件的访问授权。该版本不上传用户数据。
